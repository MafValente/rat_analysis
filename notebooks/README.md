# Notebooks

Project-specific notebooks live in separate subfolders while shared analysis code stays at the repo root.

- `ASD/`: existing ASD workflows, including the ASD-specific GLM notebook.
- `Stakes/`: the current Stakes starting point, with `01_daily_merge.ipynb`, `02_daily_animal_review.ipynb`, and `07_trial_wrangling_selector.ipynb`.

Additional Stakes notebooks can be created here as the new workflow takes shape.

Each notebook now finds the repo root automatically whether you launch it from the repo root or from one of these subfolders.
